# A股量化交易策略集 (Quantitative Trading Strategies for A-Shares)

> 面向某券商 **QMT（Quantitative Trading）策略交易端** 的内置 Python 框架实现。
> 源码原始编码为 **GBK**，本仓库已统一转码为 **UTF-8**，中文注释可直接阅读。

## 📁 项目结构

```
├── dxgp/           涨停缩量低吸策略（某券商QMT策略交易端 Python框架版）
│   ├── zt_shrink_strategy_gbk.py   # 策略主源码 (V2.6.196)
│   ├── download_trading_calendar.py

│   ├── health_check_qmt.py

│
└── nbbank/         银行股 QMT 原生多策略
    ├── gf_qmt_native_multi_gbk.py  # 策略主源码 (v1.2.100)
    └── backtest_optimize.py
```

## 🎯 策略简介

### dxgp — 涨停缩量低吸
- 面向 A 股涨停板次日缩量低吸场景
- 基于某券商 QMT 内置 Python 框架，含实时行情订阅、交易回报处理、状态持久化
- 内置账号隔离：状态/账本/黑名单/待办文件名自动带资金账号后缀（多账号/多实例不串号）

### nbbank — 银行股多策略
- 面向银行股的低波动/高股息交易
- 原生多策略框架，含回测对齐、情绪指标、仓位管理

## 🧭 运行须知

- 状态文件默认写在脚本所在目录；若 QMT 下 `__file__` 不可用，可在脚本旁放 `gf_fixed_dir.txt`
  （内容为策略绝对目录）或设置环境变量 `GF_BASE_DIR`，避免状态落到 `bin.x64`。
- 定时任务 `daily_task_runner.py` 使用当前解释器，可用 `ZT_PYTHON` / `ZT_ACCOUNT` 覆盖。
- 跨年时请按交易所公告把次年休市日补进 `_BUILTIN_CLOSED_WORKDAYS`。
